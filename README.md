**Financial Risk Management: programmazione Java
Corso Banca e Finanza - UNIVR - I° semestre A.A 2026-2027**

Repository dedicata al corso universitario di Financial Risk Management, con particolare riferimento alla prima parte del programma dedicata alla programmazione Java.

**Obiettivi**
Raccogliere e organizzare il codice sviluppato durante le lezioni universitarie e gli esercizi individuali, approfondendo progressivamente i principali concetti della programmazione orientata agli oggetti.

**Struttura del progetto**
Il codice sorgente è organizzato in package, suddivisi in base alle lezioni e agli argomenti trattati.

**Argomenti trattati**
- Fondamenti di Java
- Classi e oggetti
- Costruttori
- Incapsulamento
- Getter e setter
- Composizione e delega
- Programmazione orientata agli oggetti
- Esercizi pratici
